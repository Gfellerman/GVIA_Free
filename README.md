# Fleet Selector Agent

This is a web application to help users select the best vehicle type for their fleet.

## Background Image

There is a known issue where the application background image could not be downloaded automatically. A placeholder file `background.jpg` has been created. To add a background image, please follow these steps:

1. Download the desired background image to your computer. The image that was attempted to be used was: `https://www.pexels.com/photo/row-of-bmw-series-7-18029642/`
2. Rename the downloaded image file to `background.jpg`.
3. Replace the existing empty `background.jpg` file in the project's root directory with your new image file.
4. Refresh the application in your browser to see the new background.
